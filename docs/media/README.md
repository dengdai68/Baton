# 公开产品演示素材

这些文件供仓库首页、首次使用教程与推广文稿引用，使用相对于文档的路径，点击后进入 GitHub 图片预览。

- `workspace-collaboration.png`：任务工作空间的经理分工与员工交接。
- `team-chat.png`：沟通中的多员工群聊与 @ 定向交流。
- `workspace-files.png`：工作目录中的实际文件与 Markdown 预览。
- `quickstart.gif`：约 15 秒的数字员工、任务创建、协作记录、文件预览与群聊截图导览。
- `task-create.png`、`employees.png`：首次使用教程和推广文稿的配图。

英文 README（`README.en.md`）引用同名加 `.en` 的英文界面版本：`workspace-collaboration.en.png`、`team-chat.en.png`、`workspace-files.en.png`、`quickstart.en.gif`、`task-create.en.png`、`employees.en.png`，场景、尺寸与动图节奏与中文版一致。

素材采自 v0.1.10 桌面客户端的隔离实例（1440 × 900，浅色主题）。动图由五张实际界面截图组成，缩放为 1024 × 640，循环播放。任务、文件、协作和群聊使用公开示例数据，未调用模型；这些图片用于展示界面，不作为真实模型执行结果。英文版采自 v0.1.11-beta.2 之后的开发构建（含平台文字的界面翻译修复）的隔离实例，界面语言为 English，员工、任务、文件与群聊使用对应的英文公开示例数据，动图由五张截图各停留约 3 秒组成，同样未调用模型。未使用操作者的真实任务、聊天、凭据或私有文件。测试日志、数据库及截图脚本不属于公开素材。
