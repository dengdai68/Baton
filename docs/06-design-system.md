# 界面约定

核心功能对齐：工作流属性面板在“协作与交付设置”中暴露人员需求、交付要求、建议路径、节点类型及连线依赖/交接开关；保留主提示词与现有共享 tokens。MCP 工具面板提供搜索、20条分页及参数/返回值 schema 折叠查看，与 CLI 共用纯分页投影。

待我处理详情：任务标题后直接提供「打开任务工作区」，不固定在底部。已回答回看同时显示原任务内容、原问题、已有上下文与回答；已完成回看显示原任务内容和经理处理结果。本会话的回答快照不扩展为持久历史。发送回答只有一个主操作，回答成功或确认完成后按待处理列表顺序进入下一项；失败保留当前详情与草稿，人类确认仍经既有确认框。

任务与自动化空成员控件和流程框统一28px；多选成员chips在任务/团队/沟通中自然换行。执行计划仅保留Cron字段并与标题同行。协作和沟通按senderId对应头像色系呈现姓名、Markdown标题/强调/链接/代码/引用，浅深主题文本对比至少4.5，正文中性；未知身份不按姓名猜测。插件更新只有目录右上手动更新全部，设置不保留自动更新项。

任务协作移除「全部/涉及我」，保留最新与历史分页；安全 Markdown 使用共享强调、链接、引用和代码配色，记录区与输入框外缘对齐错误提示框，分隔线铺满滚动内容宽度。任务和沟通发送后立即显示本地发送中记录，确认后按服务端标识替换，未确认保留内容供恢复且不覆盖新草稿。工作区先显示compact元信息，再独立加载协作；控制台历史与正文仅在打开后读取，实时状态订阅保留。设置入口复用普通导航行居中，无额外顶线。

视觉语言的唯一规范是 [.interface-design/system.md](../.interface-design/system.md)（**A · 石墨**，2026-11-13 起替代此前的 B · 纸张）：取值、组件、逐页结构与「无坏界面」验收清单都以该文为准；本文只记录产品层面的交互约定、数据边界和历史决定。逐页结构以 `.interface-design/redesign/pages/*.html?style=graphite` 的渲染结果为基准，截图相近或测试通过不能替代逐区块核对。

## 石墨设计系统 · 落地要点

- **分层**：`web/tokens.css` 是唯一颜色、字体、间距与形状入口（`light-dark()` 成对声明，跟随系统由宿主 `color-scheme` 决定）；`web/styles.css` 是共享组件与页面布局，只引用 Token，不再新增十六进制颜色或页面私有色板；`apps/electron/compact.css` 只定义宿主密度。HTTP 把 tokens 与密度注入每个 HTML，原生弹窗直接读取同一 tokens 文件。
- **取值**：冷灰中性色（侧栏 #F7F7F8、正文 #1B1C22、分隔 #EFEFF2），蓝色主操作 #2558D9；字号 11/12/13/14/15/20（28 仅引导）；控件 28（sm 24 / lg 32）、行 38、导航 28；标题栏 48、工具栏 44、侧栏 232（≤1000px 为 60px 图标栏）、页边 24（≤860px 为 16）；圆角 4/6/8/12，头像为边长 30% 的大圆角方形；成员头像只显示一个字符，插件/MCP 头像可用两个字母缩写。
- **页面框架**：页面标题与计数位于 48px 标题栏（图标 + 15/600 标题 + 12px 计数），不再显示文档大标题与页面说明（目录页的说明保留在仅读屏可见的标题区）；44px 工具栏承载页签/筛选与 220px（窄屏 150px）搜索；分组头 34px、`--bg-subtle` 浅底并吸顶；卡片 1px 边框、无常驻阴影。
- **状态**：同时使用文字、图标与语义色：执行蓝、准备紫、待处理琥珀、完成青绿、错误红；员工可用不显示徽章，执行中绿点只表示实际运行。
- **验收**：`node scripts/test-redesign.mjs` 在隔离 HOME/数据库、展示夹具与禁止模型执行的测试命令下覆盖浅色/深色 × 1440/760 的核心页面和真实交互，产物只进入 `.data/ui-redesign-audit/`；它验证呈现与客户端行为，不声称验证真实 Provider 业务结果。

### 桌面与键盘

macOS 使用 hiddenInset 一体化标题栏，红绿灯坐标 (16,15)。顶部与侧栏空白为拖动区，所有交互控件明确 no-drag。1180px 以下任务属性改为默认关闭的右侧浮层（Escape/背景关闭），沟通目录 248px、群成员 224px，控制台展开时成员收为 56px 图标栏；1000px 使用图标侧栏；860px 以下沟通会话目录按需展开并带内部关闭入口，关闭归还触发按钮焦点，成员使用浮层，控制台占据完整主区域，任务文件/控制台成员区上下分栏；待办也变为上下分栏。760px 保持最小桌面窗口可用。消息、文件、控制台和抽屉各自滚动，发送与弹窗提交保持在窗口内。

⌘/Ctrl K 打开命令面板，↑↓/Enter 选择，Esc 关闭并归还焦点；/ 聚焦当前搜索、C 创建、J/K 在任务/员工/待办条目移动，仅在非编辑状态生效。⌘/Ctrl I 开关任务详情。新建任务 ⌘/Ctrl Enter 保存并开始。菜单支持方向键、Home/End、Esc，Escape 不关闭有草稿的表单。主操作禁用时不响应快捷键。

### 数据与验收边界

待办聚合等价于 CLI `tasks list --status STATUS` 的既有查询；不新增完成判定或自动恢复。列表/看板、命令面板、抽屉、标题栏计数等为呈现差异，无需新增 CLI 命令。扩展使用筛选同步 `plugins list --usage all|unused`、`mcps list --usage all|unused`，HTTP 查询 `usage` 同值，默认 all；业务资料不可读时 unused 明确失败，绝不显示假空态。详情、创建、编辑、删除、导入和原来的执行操作契约保留。

插件更新命令直接应用更新，尚无待更新候选，因此不显示“有更新”筛选；标题栏“检查并更新”明确执行全部 Git 来源更新。MCP 工具仍只在详情或重试时显式读取，计数/失败留在本会话缓存并用于失败 chips；卡片只读配置推导 stdio/SSE/HTTP，不因浏览目录启动工具进程。加载/空态/错误依据真实请求区分，失败可原位重试；员工/角色的扩展目录未就绪时禁用保存，失败重试不丢失草稿。已有不可变事件、冻结快照与人类验收边界不变。


沟通与任务协作输入共用 `web/communication.js` 的换行行为：Shift + Enter 使用原生编辑，保持光标跟随和撤销；其他修饰键换行显式定位当前光标，末尾输入跟随底部，中间编辑不跳到文末。输入法确认、@ 候选选择和 Enter 发送优先级保持不变；只滚动输入框，不滚动协作记录或整页。任务协作局部或整体刷新时保留草稿的焦点、选区方向与滚动位置。

工作流编辑器的四边连接点默认透明，悬停节点或键盘焦点可见时显示；画布按住鼠标期间显示候选连接点，松开恢复。端口结构与已有连线不变，只读工作流不展示端口；状态样式集中在 web/styles.css。画布 SVG 读取共享语义颜色，新增节点聚焦标题时使用 preventScroll，避免移动现有画布。自动化从目录摘要打开工作流时按 ID 读取完整定义。

工作目录页签行移除下分隔线，当前文件/文件变更 共用右侧无边框刷新图标；文件变更 移除更改计数工具栏，对比布局/范围移入文件预览标题右侧，与当前文件保持同一标题结构。刷新忙碌/失败恢复及原文件选择语义不变。共享弹窗改用原生 dialog 维护键盘模态与焦点返回，居中表单仍仅显式关闭，目录编辑抽屉点击外部或 Escape 关闭；统一 Runtime 同行字段、设置选中态、主题预览和语义焦点 tokens，移除弹窗硬编码阴影并支持减少动画。桌面维持紧凑尺寸，粗指针操作使用 44px 点击区。仅界面/交互变化，无 App/CLI/HTTP/Store 契约变化。

配置表单复用现有 form-field：员工简介与可增删的能力标签分开，能力仍提交原字符串数组；员工和团队用“可用”复选框映射 active/inactive，团队成员选择可空。任务验收标准放可选折叠区，保持底部成员/工作流和提交操作可达。

任务成员与群聊成员使用 createEmployeeMultiSelect，团队候选只展开为员工标签，已选项显示在同一输入边框中，重复员工去重；经理冲突候选禁用且说明原因。团队表单同样使用框内多选，不单独要求经理。群聊右侧成员列表/详情和最右控制台复用 tokens 与共享日志 renderer，窄屏支持关闭和键盘焦点归还。

协作读模型以消息/事件为主线，按 sourceMessageId 或唯一的已有定向消息、Dispatch/Trace 引用关联真实派工；不按正文、名字或时间猜测，不回填历史。deliveries 明示投递当前状态，history 保留每次执行与重试的实际时间，经理协调为全流程范围。CLI 保留完整投递/执行事实、验收关联及有界文件 ID/名称引用（files 最多8项、fileCount 为总数）；完整文件列表用 artifacts 查询。已知员工交接结果信封从 rawResponse 提取已记录的报告正文，去除重复结构化结果，原始消息和控制台事实不变。客户端协作区展示成员总结、沟通和关键人类状态，保留单一“本轮控制台”入口；不自动附加投递状态、技术失败/重试通知、验收文件清单或平台验收说明。长消息全文一次渲染 Markdown，超过10行仅收起区域，展开不重建 DOM，Run 内保留阅读状态。控制台无顶部错误摘要，失败记录在日志内标红；员工状态按自己的最新 Trace 显示错误/执行中/正常，重试成功后清除旧错误。未验证事项保留员工原文，不自动判定交付质量；存储、调度、模型输入和人类确认规则不变。

协作记录只展示员工、经理、人类之间的沟通 Message；系统提示、启动、投递、重试和结算事件不作为记录行。底层不可变事件、Dispatch 和 Trace 继续保留，关联执行元数据供查询。消息保存本轮 `startMessageId`，对应 Trace 的 `inputMessageId`；“本轮控制台”按该 ID 打开、定位本次提示词，不受日志分页影响。成员原生会话贯穿任务且彼此隔离，每次执行拥有独立输入轮次 ID。 新任务与经理协调统一显示“进行中”，错误显示“错误中断”；错误期间禁用输入框与 @，保留原员工重试入口。

工作目录按完整真实路径组织，当前文件按需展开与分页继续加载，文件变更复用同一层级/图标并保留删除项；目录加载/错误/重试只属于该目录，不因全树重建切走文件选择。大文件仍提供元数据与下载。

插件自动更新控制集中在设置的「更新」分类中的插件更新模块，开关即时保存、周期失焦校验保存，保留立即检查；市场不混入运行设置。后台状态刷新不覆盖未保存输入。沟通初次无选择时显示最后更新会话；任务控制台初次无选择时显示最近开始执行的成员，之后尊重显式选择，不因刷新跳转。

人类协作记录保留全宽分隔线，时间、类型、收发人及状态置于正文气泡外并右对齐；正文气泡最大 72%，上下 8px、左右 14px 内边距，不强设最小宽度，首尾段落不额外留白。已知成员的 @提及使用与成员名称一致的深色粗体，不改变路由或 Markdown 代码/链接内容。员工消息靠左，28px 方圆头像后留 16px 正文缩进，姓名/类型/月日及时间同行，非当年加年份，完整时间放在 title；按真实本地日期分隔。

协作流只按真实消息时间展示经理结论、交接与后续提问，不在列表末尾附加固定的验收说明副本。确认完成仍是顶部独立的人类操作；不展示「停止答疑」，未归档任务保留输入，归档后只读。删除被进行中的答疑阻塞时提示等待答复，不引导不存在的界面入口。

任务和沟通控制台不平铺无正文的开始/保存、普通会话连接、空 Provider 进度或诊断占位通知。保留正文、思考、工具、提示词，以及失败、重试、取消、会话重建和恢复；未知消息不默认隐藏。完整原始事件与详细诊断仍在原有审计/日志中，不改变执行状态、分页或 CLI/API。

团队、工作流和员工的标题与计数位于48px标题栏，创建也在标题栏，搜索/筛选在44px工具栏，内容单独滚动。团队/角色整行分隔延伸至页边，卡片内容使用统一页边距。筛选前后保持服务端分页，输入和焦点不被刷新销毁。

任务和沟通控制台共用同一 renderer/hydrator：本次提示词完整展开已脱敏系统指令和本轮输入，下面显示对应已确认 Claude Code/Codex 原生会话 ID，未记录时如实标注。移除长快照说明和工具审计详情；截断/缺失仍明确提示。同一工具调用的重复阶段和相同公开输入不重复展示，不合并不同 ID 的真实调用。空 tool_progress 通知隐藏。侧栏、Dock 和安装包使用用户 A 图标的同源派生资源，菜单栏单独使用无底板单色模板。

沟通控制台顶部保留当前员工身份、真实执行状态、「最新」「刷新」和关闭入口；不渲染成员切换页签，群聊从右侧成员栏的控制台按钮切换，历史分页保留在记录内。日志按真实 Trace 的相邻时间段组成默认展开的执行卡，不改变时间顺序，卡头只统计当前已加载条数；提示词与工具仍保留各自折叠和按需读取。保留成员查询、错误显示和阅读状态，不变更执行协议。

插件/MCP 卡片和详情复用员工头像形状与五色 palette，按稳定安装 ID 配色。沟通输入仅保留可访问名称，不显示冗余「消息」标签；附件添加、待发移除、下载支持键盘。列表只标记真实 unreadCount，移除 pending 点。私聊标题栏右上角提供图标和「控制台」文字入口及 aria-expanded，展开后聊天与控制台各占一半，日志顶部可关闭；开关保留输入草稿。群聊控制台宽屏保留 216px 成员栏，1180px 以下收为 56px 身份图标栏；860px 以下控制台占据完整主区域，关闭回聊天。会话目录覆盖打开时自带「返回会话」关闭按钮并归还焦点。面板内部滚动、文件名省略不撑宽、发送按钮保持可见；工具/思考/正文复用任务控制台格式化。

员工插件/MCP 下拉不长期遮挡下方字段：鼠标移出选择区或焦点离开搜索/候选区时收起，点击表单其他区域也收起。鼠标从输入移动到候选项（含间隙）不能提前消失；复点输入重开，方向键与 Enter 选择，Escape 收起并保留编辑框，隐藏候选不遗留不可见焦点。收起不清空查询或更改员工选择。

员工、插件、MCP 卡片共用171px结构：40px身份区（36px头像）、40px两行简介、33px页脚，段间距12px；姓名下为角色或来源，底部元信息和常驻操作同排。空白或长简介不改变关键位置，悬停不覆盖内容；员工可切换38px行列表。插件详情只有正文滚动（含概览与全部组件），组件标签吸顶，标题栏操作固定可见；不可通过裁剪隐藏长列表，也不以限制 Skill 数量代替滚动。

员工、插件/MCP目录使用共享entity-card结构：头像/名称/角色或来源、两行描述、稳定底部元信息与操作。创建/手动安装在标题栏，搜索在独立工具栏；详情使用固定头部与可滚动正文的右抽屉，危险操作进入更多菜单和原有应用内确认。

插件/MCP 未安装、搜索无匹配、加载中和读取失败均使用卡片网格之外的独立整行状态区，不按一张卡片的宽度展示，不把读取失败误报为空市场。

renderer 与 Electron 共享真实语义和命令。优先使用现有颜色、字体、间距、焦点和按钮样式；共享组件位于 `web/styles.css`，`apps/electron/compact.css` 只保留密度。

角色侧栏入口使用继承当前文字颜色的 SVG 人物名牌图标，宽窄窗口不依赖字体字形。角色与其他可选入口一同登记在 `preferences.mjs` 的 NAVIGATION 中，外观设置可隐藏并持久保存，恢复默认会重新显示；配置分组内全部入口隐藏时分组也隐藏。这些都是客户端展示偏好，不改变角色配置或 CLI 协议。

- 列表提供搜索、分页和明确空态；不一次平铺大型员工目录。
- 团队编辑按名称或能力搜索员工，最多显示 20 个候选；已选员工以带16px头像的可移除标签保留在同一输入边框内。“用此团队新建任务”预选有效成员，由用户另行指定本次经理。
- 工作流详情的节点导航只显示标题，完整说明在内容区展示；编辑节点可折叠。
- 长配置弹窗宽高随视口变化，正文内部滚动，底部操作可见；小窗口切换单列。
- Markdown 通过本地 marked + DOMPurify 渲染，加载失败显示转义文本。
- Shell 保留原始换行和终端主题；Edit 差异逐行展示，不插入额外空行。
- 工作目录只有「当前文件」和「文件变更」：两者复用目录树、目录优先排序、图标、缩进与折叠逻辑，分别展示当前文件与发生变化的文件；文件变更 的布局与范围图标组和刷新右对齐，支持行内/左右、仅差异/完整文件。
- 工作目录使用 vscode-icons 子集，主题仅作用于工作目录树和选中文件预览。
- 当前文件与 文件变更 的根目录按内容紧凑排列，折叠后不留分组空白。当前文件的下载位于文件预览标题右侧，刷新图标位于“当前文件 / 文件变更”页签行右侧，未选文件禁用下载；读取失败就地提示，不以导航错误页替代任务页面。
- 文件变更 不在各目录下显示「没有更改」；仅全部成功读取且无变化时展示一次整体空态，读取失败、未初始化与加载中不得误报无变化。
- 控制台、协作记录使用可用窗口宽度；日志和重内容按需加载。
- 提示词按 Trace 开始时间排列，每个调用只出现一次；分页尚未覆盖其时间时不提前固定展示，加载旧页后按时间合并，正文仍按需读取。
- 执行中的任务/沟通成员以头像角落的绿色点表示；错误与等待保留独立文字，终态恢复中性。成员行选中使用中性填充色，协作正文保持正文色，待答问题用琥珀色卡片及明确回复入口。状态文字保留，颜色不代表业务通过。
- 私聊/群聊沿用上述色彩，人类蓝色、员工按稳定身份使用青绿/紫色；强调姓名、已有加粗/标题和引用，正文保持中性色。桌面保留紧凑记录，使用紧凑对话呈现。
- 协作记录和沟通按实际发送者布局：人类消息靠右，员工消息靠左（包括员工发给人类的消息）；不是按“涉及人类”筛选标记判断。人类记录宽度有上限，正文仍左对齐以便阅读 Markdown/代码；保持时间顺序、回复入口和分页语义。
- 控制台不再次回显 `message.sent` 协作正文；正文在协作记录保留，Runtime 输出和失败等执行事实仍显示。任务标题左侧提供有可访问名称的返回列表图标按钮，和标题保留明确间距，返回时保留任务搜索条件。
- 控制台可见工具行无需展开即可显示 Bash 命令、Read/Write 文件路径；这三类连续调用的分组默认展开行摘要，用户仍可收起。摘要仅来自已脱敏且通过完整性校验的执行内容。成功 Read 展开显示 Done，失败保留错误；Write 展开直接呈现写入文本及脱敏/截断提示，无法解析时如实回退。
- 图标按钮具备可访问名称，选中态可辨识，键盘可以完成搜索、选择和关闭。

退出入口位于设置 → 常规底部。任务详情在宽于 1180px 的协作页默认展开，文件和控制台页默认关闭；1180px 以下统一默认关闭，打开为右侧浮层。任务描述显示前 100 字并可展开。

所有目录的未创建及搜索无结果共用 `.directory-empty`；不在空态重复创建按钮，入口保留在标题栏。

任务、团队、工作流、员工、角色、MCP/插件及沟通选择目录共用 `.directory-empty`，宽窄布局一致。

## 品牌颜色与目录状态

应用以用户提供的蓝/青/紫缎带 A 图标为品牌来源：主操作和焦点使用 `--accent` #2558d9（悬停 #1e46b7、浅底 #eef3ff、边框 #c9d7fa，深色 #3d6bf0），选中行与导航使用中性填充 `--bg-active` 而不是彩色；完成用青绿 `--st-done` #0d7a68，准备/条件用紫 `--st-planning` #6b4ec4。石墨中性色：正文 #1b1c22、次级 #5c5f6a、辅助 #8a8d97，侧栏 #f7f7f8、浅底 #f8f8f9、边框 #e4e4e9 / 分隔 #efeff2。完整浅深取值见 `.interface-design/system.md` 第 2.1 节。禁止为单个页面新写一套徽标配色。

员工“可用”和静态 Runtime“支持”采用品牌蓝；不支持/停用用中性文字与浅底，失败用红，待人类处理用琥珀。文字始终保留，颜色不代表业务验收通过。能力标签用中性浅底，员工/扩展头像采用同一组紫、青、橙、绿、蓝高区分度实色与白色字形，维持可读对比。

目录空态共用 `.directory-empty`：宽度100%、跨网格所有列、48px 24px内边距，无虚线框；40px语义图标、15px标题、13px说明居中。不得叠加 `.empty-state` 或页面级边框。加载和读取失败保留真实状态，失败使用 alert，不伪装为无结果。

## 目录与 Runtime 呈现补充

角色与其他目录共用上述居中空态。生成头像使用高区分度的紫、青、橙、绿、蓝实色与白色字形，不限于品牌色；品牌按钮、焦点与状态标签保持语义 tokens。任务工作区使用 48px 一体化标题栏，任务 h3 为 var(--fs-body)（13px），同排保留状态与操作，44px 页签栏位于标题栏和内容分栏之间；目录标题不受影响。Runtime 为固定两行，开关表达可用性；配置默认折叠，页内展开编辑模型与思考等级；子标题字号严格小于所属设置主标题。Runtime 模型和思考等级同排；两种候选列表均距输入框4px，间隙保持可悬停，空间允许时完整展示六项；模型及思考档位仅展示标签首字母大写，原始 ID/提交值保持不变。

Runtime、GitHub/GitLab 都是所属设置标题的二级配置组；桌面使用紧凑分隔行，Runtime 上下10px、页内编辑顶部12px，仓库配置上下12px，避免层层卡片与重复大留白。表单控件、说明、焦点及分隔仍清晰可辨。任务中心操作列常显并左对齐当前允许的下一步和更多菜单（编辑、归档、删除）；窄屏按钮可换行，删除确认和服务端可操作性门禁不变。

新建任务使用内容优先的独立弹框：标题、随可用高度在六至十二行之间调整的内容描述；输入框最高十二行，更多文字在框内滚动，弹框随内容收紧。验收标准默认折叠、可留空，收起保留草稿，无效输入自动展开显示错误。团队和流程两项位于底部同排，工作目录仅一行小字提示；不展开执行说明、经理配置或流程人员/节点详情。底部提交固定可达，短窗口由正文区滚动。字段、冻结与启动协议不变。

常规的关闭选项保持两项同排；GitHub/GitLab 的 Token 输入、保存和移除操作同排。Runtime 模型/思考等级同排，展开时隐藏重复摘要，保留字段错误与一条总提示；普通状态不再逐字段重复说明。任务详情的工作目录在「复制」后提供「打开」，由受限宿主打开当前 Run 文件夹，失败就地提示且保留页面。

实时同步状态只在侧栏底部登录信息旁展示一次，不占各页顶栏；窄窗口隐藏文字但保留状态圆点、可访问名称和悬停说明。连接及断开状态仍由实际任务事件流更新。

应用图标保留用户提供的 1536×1536 原始 PNG 字节与完整构图，不放大裁切；侧栏使用标准圆角彩色图，Dock/安装包使用相同的 824/1024 图形比例及透明留白，避免图标过大或白色底板。顶部菜单栏使用独立的 18pt/2x 单色 A 模板，随 macOS 明暗背景和选中状态变色。详见 web/icons/README.md；无 CLI/API 或任务协议变化。

更新 Tab 不重复显示“更新”标题，直接以与常规/外观配置相同层级的“应用更新”和“插件更新”分组；当前版本同行附简短 GitHub 文字链接，窄屏自然换行，不单列仓库地址。应用更新的信息和按钮集中在“设置 → 更新 → 应用更新”区域；自动检测结果、下载进度和下载完成状态就地更新，不创建全局通知卡或自动切换页面。区域重新打开时读取宿主最新状态，检查、下载、安装仍由现有按钮触发。

Runtime 设置现在固定 Claude Code/Codex/DeepSeek Harness 三行；DeepSeek Harness 使用同一页内折叠、可用开关和同行模型/思考控件，模型名称及 Off/Low/High/Max 显示标签不改变实际值。目录/员工/控制台使用 DeepSeek Harness 名称；扩展标签只按当前安装版本的兼容声明展示，不把 DeepSeek Harness 显示成 Claude Code。

Runtime 展示名称为 Claude Code、Codex、DeepSeek Harness，内部 Provider/CLI 命令仍为 claude-code/codex/dsh。服务通过与执行相同的 CLI 环境检查可执行文件（不运行模型、不读取凭据）；Store 注入该只读事实，在 list/get 返回 installed 和实际 enabled。未安装或客户端 PATH 找不到可执行文件时 enabled=false、界面开关关闭并锁定，HTTP/CLI 拒绝修改 enabled 和发起新调用；安装检查不改写用户开关偏好、员工或 Task 冻结事实。安装/PATH 修复后重开客户端或重新进入 Runtime 设置重新读取；已安装但未登录不属于未安装。

协作工具栏仅保留右侧「最新」，移除「全部/涉及我」筛选，不重复协作标题、不展示总条数或强制 @ 提示；答复直接展示正文，不重复附加“回复的问题”折叠块，历史回复关系保留。未 @ 默认交给项目经理，输入框只提示输入消息。任务和沟通控制台的会话 ID 与同一提示词内容框左边缘对齐，复用 prompt-snapshot 的 26px 内容缩进。

控制台 Markdown 正文使用时间线单一纵向滚动；不再为普通正文叠加内层高度上限/纵向滚动条。列表编号保留两字宽缩进，代码块与宽表格仍可横向滚动。

插件和 MCP 市场卡片不展示支持的 Runtime 标签：标题行显示真实版本或连接类型，次行显示来源或安装日期，页脚显示组件/工具与员工用量。点击卡片打开右侧详情，头部保留检查兼容性或编辑及更多菜单；正文展示兼容性矩阵、具体原因和使用员工，卡片精简不代表所有业务依赖已实测。

应用下载进度在同一行显示进度条和右侧百分比，无独立进度提示卡；下载期间隐藏下方说明框，结束后恢复安装说明。百分比使用等宽数字，100% 在窄窗口中也不换行；原生进度条保留可访问名称与数值。

员工角色、插件和 MCP 采用同一个框内多选控件：已选项以可移除标签与搜索输入共用边框，长标签省略，已选区横向滚动，不在框外再设已选区；角色没有序号、上下箭头或优先级说明。使用共享 surface/line/accent 焦点 tokens，窄屏与两主题保持相同结构。

沟通新建对话沿用框内选人，不要求群标题。单聊无成员栏，标题区用图标和「控制台」文字入口；群聊成员栏宽 248px（控制台展开时 216px），显示人数、24px 员工头像与单行省略姓名，固定控制台按钮不被长姓名挤压；1180px 以下成员栏 224px，控制台展开后收为 56px 身份图标栏。员工详情用与编辑群聊相同的居中 dialog，仅展示信息。群聊标题区可双击或用键盘 Enter/F2 编辑，Enter 保存；控制台只显示所选员工，成员切换在群成员栏完成，窄屏保留关闭与返回入口。新建/编辑沟通的关闭按钮置于底部主操作左侧，打开时聚焦关闭按钮，主动进入选人框才展开候选。

自定义候选列表共用 `web/floating-list.mjs`：原生手动 Popover 顶层容器保留原 DOM 归属，内部列表滚动，透明 4px 间隔保持鼠标连续可达；根据锚点与窗口剩余空间，优先下方、空间不足时上方，滚动/窗口变化时重新定位。团队/任务/员工的角色、插件、MCP/成员多选，以及 Runtime 模型与 @ 候选均复用，不受弹框内部 overflow 裁剪。原生 select 继续由浏览器定位，不改原始提交值。

## 通知层级

共享页面反馈由 `web/toast.mjs` 管理，复用 `.toast` 的既有语义色、右下角位置和时长。toast 必须位于原生 dialog、媒体预览及候选 Popover 之上：使用 `popover=manual` 顶层，在后续浮层打开时重新置顶。无交互、无焦点抢占、无背景遮罩、pointer-events:none；成功为 status、错误为 alert，减少动画偏好关闭过渡。`.toast[popover]` 以显式 inset/margin 清除 UA 默认居中，最大宽度限制在窗口内。原生系统通知另由 Electron 负责，不与 toast 混用。两主题宽窄及晚开模态验证见 `scripts/test-desktop-notifications.mjs`。
石墨设计系统（2026-11-13 起替代纸张，规范见 .interface-design/system.md）：`web/tokens.css` 是唯一 Token 源（服务端注入每个 HTML），语义 Token 成对 light-dark() 声明，color-scheme 随设置 → 外观（浅色/深色/跟随系统，默认浅色）；旧 warm/minimal 取值拒绝并回落浅色，无迁移。外观偏好经宿主桥同步原生窗口并持久化。侧栏选中=填充、页签/筛选/设置导航统一填充选中；头像 30% 大圆角方形、单字符；绿点只表示执行中；协作与沟通记录区 fluid 留白 + 细分隔线，自己的消息为右侧气泡；VS Code 工作目录配色默认跟随外观，文件预览底色使用 `--bg-canvas`。契约与验证见 ai/module-registry.json → interface-graphite、docs/18-electron-client.md「外观」、scripts/test-redesign.mjs。

自动化使用紧凑表格行、原生开关、规则大小两行与成员堆叠；角色使用全宽行按钮（身份/名称/单行提示词/最多5个员工头像/相对时间），更多菜单独立保留删除确认。角色当前无 updatedAt 时明确回退 createdAt，悬停标为创建时间。扩展卡片保留两行描述，标题行版本/类型标签、来源行和组件/工具及员工用量页脚。登录与初始化为最大360px、左对齐、垂直居中的无卡片内容组，共用主题 tokens。

非模态目录抽屉的 directory-detail-header 显式使用 -webkit-app-region:no-drag，覆盖其下方宿主 topbar 的窗口拖动区域，使编辑、更多与关闭按钮响应真实鼠标点击；键盘行为及目录外拖动不变。

控制台打开时持续增量接收；阅读历史只暂停自动滚动，不丢事件或停止查询。在底部及点击「最新」后持续跟随，延迟正文、Markdown 与布局变高不会解除跟随；向上阅读按可见记录锚点保留位置及展开状态。任务/私聊/群聊共用 console-stream.mjs，加载更早记录水平居中。实时窗口上限200条；断线/突发用现有 before 分页补齐，相邻页无交集时只显示真实最新窗口，历史仍可分页读取。

显式分页回看的窗口与最新尾部分别保留最多200条；此时新记录进入独立尾部缓存，不会把历史阅读窗口替换为最新页。点击「最新」或滚到历史窗口末尾恢复实时跟随。

多语言排版：界面文字一律经 `$t` 输出，组件不得依赖中文宽度；按钮、标签、表头与导航需容纳英文更长文本（允许换行或省略并保留 title），窄屏仍可用。日期时间用 `Intl` 按当前语言格式化，简体中文保持原格式。繁体使用台湾用语（數位員工、主控台、儲存庫、工作流程、外掛等）。
