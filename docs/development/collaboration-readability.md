# 协作记录可读性改进与审阅

日期：2026-10-31。初轮版本：0.1.1-beta.93；最终安装版本：0.1.1-beta.96。源码基线为 44034ae，本轮 main 工作区包含完整协作时间线及可读性改进；未推送或发布。

目标：让操作者看清目标、谁交给谁、每次执行与恢复如何发生、哪次交付得到人类确认。范围为共享展示投影、renderer、CLI 读模型和文档；不修改调度、Provider 提示词、任务结果或历史事实，不新增业务质量门禁。

## 实现与证据

- 主线保留每条协作消息和关键状态，按实际消息/事件时间排序；投递当前状态明确放入 deliveries，逐次 Trace 的开始/结束与重试等事件留在 history，不把最终状态投回建立时间。
- 优先使用 sourceMessageId；已有唯一的定向消息、message 引用或源 Dispatch/Trace 引用也能恢复关联。歧义或缺失明确注明，不按正文/名字/时间猜测，不回填持久数据。经理协调显示全流程范围。
- 同次经理验收说明归入经理原文；人类确认引用该次验收，保留原有未验证事项，不自动解释或改判业务结论。文件仅提供验收时的有界 ID/名称引用，打开的是明确标注的当前工作文件。
- 长消息可展开全文，执行明细和文件入口可展开；Run 内保留阅读状态。CLI 同步记录时间与当前状态的区别，继续使用认证 HTTP，不扩大写入权限。
