# 工作空间服务与 iOS

每个 Baton 服务实例拥有一个工作空间和一份业务数据库。云端由多个人类账号共用，本地使用 human_operator。手机、桌面浏览器访问同一 HTTPS 界面和 API。Electron 的原有管理接口仍受本机认证保护。网络接口逐操作授权，任务和自动化默认只对创建者可见，可指定负责人、协作者和只读成员。自动化运行继承定义的访问权限。私聊按用户和员工隔离。工作空间成员属于同一信任团队，Agent 使用实例运行账户的操作系统权限，部署应使用专用操作系统账号和工作目录。

手机通过系统信任的 HTTPS 登录云端。本地使用包含证书指纹和短时一次性票据的配对链接，配对兑换成能单独撤销的设备会话。Relay 使用标准 SSH 远程 TCP 转发，一个应用一把公钥和一个预分配端口。TLS 在 Baton 和客户端之间终止。每个实例独享工作目录。部署步骤见 apps/ios/README.md。

| 部署 | 登录 | 手机路径 |
| --- | --- | --- |
| 本地单账号 | 桌面配对并可撤销设备 | iOS → 局域网 HTTPS 或通用 Relay → Baton |
| 云端多人 | 每人独立账号 | iOS 或桌面 → HTTPS → Baton |

需要验收或回复的普通任务仅进入有处理权限成员的待办。任一成员提交验收后，所有成员看到相同的结果和实际处理人。自动化异常按定义当前的成员权限展示。手机发送消息、创建任务和手动触发支持断线后重发。云端成员管理和共享资源配置由主机运营者执行。Relay 无需知道任务、账号或工作空间，连接端可用标准 OpenSSH 或附带的自动重连程序。见 [安装和连接步骤](../apps/ios/README.md)。

iOS 在连接失败时显示系统错误，并允许用户在同一地址重新连接。本地重试沿用配对时绑定的证书指纹。
