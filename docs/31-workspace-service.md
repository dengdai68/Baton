# 工作空间服务与 iOS

每个 Baton 服务实例拥有一个工作空间和一份业务数据库。云端由多个人类账号共用，本地使用 human_operator。手机和桌面浏览器使用相同的工作空间界面和 API。Electron 的原有管理接口仍受本机认证保护。网络接口逐操作授权，任务和自动化默认只对创建者可见，可指定负责人、协作者和只读成员。自动化运行继承定义的访问权限。私聊按用户和员工隔离。工作空间成员属于同一信任团队，Agent 使用实例运行账户的操作系统权限，部署应使用专用操作系统账号和工作目录。

手机通过系统信任的 HTTPS 登录云端。Mac 托管的服务使用管理员账号登录，每次登录建立可撤销的设备会话。Relay 使用标准 SSH 远程 TCP 转发，一个应用一把公钥和一个预分配端口。TLS 在 Baton 和客户端之间终止。每个实例独享工作目录。部署步骤见 apps/ios/README.md。

| 部署 | 登录 | 手机路径 |
| --- | --- | --- |
| 本地单账号 | 工作空间地址和管理员账号 | iOS → 局域网 HTTPS 或通用 Relay → Baton |
| 云端多人 | 每人独立账号 | iOS 或桌面 → HTTPS → Baton |

需要验收或回复的普通任务仅进入有处理权限成员的待办。任一成员提交验收后，所有成员看到相同的结果和实际处理人。自动化异常按定义当前的成员权限展示。手机发送消息、创建任务和手动触发支持断线后重发。云端成员管理和共享资源配置由主机运营者执行。Relay 无需知道任务、账号或工作空间，连接端可用标准 OpenSSH 或附带的自动重连程序。见 [安装和连接步骤](../apps/ios/README.md)。

iOS 在连接失败时显示系统错误，并允许用户在同一地址重新连接。使用 HTTPS 时，已登录的 iPhone 重连时校验登录时确认的服务器证书。

## iPhone 客户端（apps/mobile）

登录页在登录按钮下方选择工作空间，可在弹窗中保存 Mac 的局域网或公网地址。下拉列表用无凭据的 GET /healthz 检查 Baton 工作空间服务；每次登录只进入所选的一个空间。首次连接自签名证书时先核对指纹。成功后钥匙串仅保存当前授权，退出时撤销。设置页只读显示名称、登录地址和当前账号。

本机工作空间的 HTTPS 网关验证同一管理员密码。设备会话关联账号及凭据版本，管理员重置凭据后旧授权失效。配置写入受设备范围约束，云端成员按资源授权。设备列表仅列出当前账号有效会话。

手机控制台与 Mac 共用 `client/console-projections.mjs` 投影：调用卡片、提示词快照、连续 Read 合并、Edit 差异、Shell 终端块与思考内容一致；任务文件的「变更」「交付快照」按目录树展示；任务详情可增删成员（与沟通群成员管理相同，执行中或有待交接的员工与当前项目经理不可移除）；自动化详情以自动化标题为页面标题，布局与任务详情一致。

## 工作空间目录与实时连接

Mac 登录时可选择本机或已保存的外部地址。两端登录页均可在按钮下方添加地址。省略协议使用 HTTPS，明确填写 http:// 则使用明文 HTTP，密码及会话信息不受传输加密保护。Mac 默认托管 HTTPS 服务；单独部署时可在 workspace init 指定 HTTP origin。外部登录使用独立沙箱窗口，主机管理接口仅在本机生效。设置页展示当前机器、空间和登录设备的 IP，本机额外提供工作目录、后台服务开关和清除数据。

已认证的 Mac 和已登录设备使用 `GET /api/workspace/events`。连接就绪后，`workspace-change` 按批次通知任务、沟通、自动化及两类控制台发生变化；客户端通过各自的已授权分页接口补读。Mac 可用 `runId` 在同一连接订阅当前运行的详细事件。心跳持续校验会话，设备撤销、退出和应用切入后台都会结束相应订阅。旧 Run 流仍服务已有调用者。
