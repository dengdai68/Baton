# AgentForge · 石墨设计系统（A · Graphite）

> 2026-11-13 用户确认：生产客户端唯一视觉方向改为 **A「石墨」**，替代此前落地的 B「纸张」。B / C 只保留在 `redesign/` 作对比，不进入主题偏好。
> 基准：`redesign/pages/*.html?style=graphite` 的渲染结果及 `redesign/assets/{tokens,components}.css` 的石墨取值（下文尺寸为 Chrome 实测 CSS px）。产品数据与命令边界见 [docs/06-design-system.md](../docs/06-design-system.md)，贡献规则见 `AGENTS.md`。
> 测试通过、截图相近都不等于设计一致；验收以本文第 9 节「无坏界面」清单逐页核对。

## 1. 方向

参考 Linear / Multica：**冷静中性灰、高密度、细分隔线、分组标题带浅底**。它是一个每天要长时间使用的工作台，不是阅读型文档：信息密度优先、层级靠字重和灰阶，品牌感来自应用图标与唯一的蓝色强调色。

六条原则（适用于每一页）：

1. **内容优先，界面退后**：用边线和留白组织信息；页面内容不用阴影、渐变和装饰色块，只有浮层（菜单、抽屉、弹窗）有阴影。
2. **默认安静，异常发声**：只有需要人行动的状态（澄清、验收、中断）才用强调色；「可用」「空闲」这类常态不着色、不加徽章。
3. **一个区域一个主操作**：蓝色实底按钮每个区域最多一个，表示「下一步」；筛选与切换用分段控件；危险操作进菜单并二次确认。
4. **键盘与鼠标等价**：⌘K 是全局入口；焦点始终可见；弹窗、抽屉关闭后焦点回到触发处。
5. **像原生 Mac 应用**：一体化标题栏、系统字体、可拖动空白、只有内容区滚动，尊重深色模式与减少动画。
6. **呈现事实，不替用户判断**：状态色、协作焦点只呈现已记录的协调事实，不暗示业务结果已通过；最终完成由人确认。

## 2. Token（唯一来源 `web/tokens.css`）

三层结构：**基础色板**只在 tokens 内出现 → **语义 Token**（`--bg-* --text-* --border-* --accent-* --st-*`）是组件唯一颜色来源 → **组件 Token**（`--control-h --row-h --nav-h --r-* --pad-page`）控制尺寸。浅色 / 深色用 `light-dark()` 成对声明，跟随系统由宿主 `color-scheme` 决定。组件层禁止十六进制、rgb 字面量和页面私有色板。

### 2.3 间距、尺寸、圆角、层级、动效

- **间距**（4px 网格）：2 · 4 · 6 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48（`--sp-1…11`）。控件内边距 8/12；组件间距 8/12/16；区块间距 24/32。
- **尺寸**：

| Token | 值 | 说明 |
| --- | --- | --- |
| `--control-h` / `-sm` / `-lg` | 28 / 24 / 32 | 按钮、输入、选择；sm 用于行内与卡片页脚，lg 用于登录与大表单 |
| `--row-h` | 38 | 列表行、表格行最小高度 |
| `--nav-h` | 28 | 侧栏与设置导航项 |
| `--header-h` | 48 | 标题栏（含侧栏顶部红绿灯区） |
| `--toolbar-h` | 44 | 工具栏、任务页签栏 |
| `--sidebar-w` | 232 | ≤1000px 或手动收起为 60px 图标栏 |
| `--inspector-w` | 320 | 任务属性栏 |
| `--pad-page` | 24 | 页边；≤860px 为 16 |
| `--pad-record` | clamp(16px, 3vw, 40px) | 协作 / 沟通记录左右留白，不设最大宽度 |
| 搜索框 | 220 | ≤860px 为 150 |

- **圆角**：`--r-xs` 4（标签、kbd、代码）· `--r-sm` 6（按钮、输入、导航、菜单项）· `--r-md` 8（卡片、设置框、提问卡、轨迹卡）· `--r-lg` 12（弹窗、抽屉、命令面板、输入卡片）· `--r-full`（状态胶囊、计数、圆点）。头像为大圆角方形：圆角 = 边长 × 0.3。
- **层级**：`--z-sticky` 10 → `--z-dropdown` 40 → `--z-drawer` 60 → `--z-dialog` 80 → `--z-palette` 90 → `--z-toast` 100。
- **动效**：120ms（悬停、颜色）/ 180ms（淡入）/ 240ms（弹窗、抽屉）；缓动 `cubic-bezier(.2,0,0,1)`。`prefers-reduced-motion` 时全部为 0，并停止脉冲、旋转、骨架闪烁。

## 3. 页面框架

```
┌──────────┬───────────────────────────────────────────────┐
│ 侧栏 232  │ 标题栏 48：图标 · 标题 15/600 · 计数 │ 拖动空白 │ 视图切换 · 主操作 │
│          ├───────────────────────────────────────────────┤
│          │ 工具栏 44：页签/筛选（左） │ 空白 │ 搜索 220 · 筛选（右）  │
│          ├───────────────────────────────────────────────┤
│          │ 内容区（独立滚动）                               │
└──────────┴───────────────────────────────────────────────┘
```

- **侧栏**（`--bg-sidebar`，右侧 1px `--border-subtle`，内边距 0 8 8）：48px 顶部（红绿灯区，右侧 24px 收起按钮）→ 32px 品牌行（20px 图标 + 13/600 名称 + 新建任务图标）→ 28px 搜索入口（白底细边框，12px 占位，右侧 `⌘K`）→ 导航分组「工作 / 组织 / 扩展」（11/500 tertiary 分组名，组间 12px）→ 弹性空白 → 底部「设置」与 40px 用户卡；设置入口复用28px导航行，无额外顶线或顶部内边距，图标和文字在选中背景内垂直居中。导航项 28px、6px 圆角、13/500：未选中 secondary + tertiary 图标；悬停 `--bg-hover`；选中 `--bg-active` + 正文色，不用彩色。徽章：待我处理为琥珀浅底计数，沟通未读为蓝色实底计数。
- **标题栏**：48px、底部 1px `--border-subtle`、左 24 右 16。左侧 16px tertiary 图标 + 标题 15/600 + 计数 12 tertiary；中间空白可拖动；右侧操作组间距 6px，最多一个主按钮。所有交互控件 `no-drag`。
- **工具栏**：最小 44px、底部 1px `--border-subtle`、内边距 6 16 6 24。左侧填充式页签（vtab 28px）或筛选下拉（ghost sm）；右侧搜索 220px 与 ghost「筛选」。工具栏不放主操作。
- **内容区**：独立滚动。列表从左缘贯通到右缘（行内左 24 右 16）；卡片网格放在 `.page`（内边距 20 24 40）里，网格间距 12，卡片最小宽 300。
- **不出现**：文档大标题、页面说明段落、标题栏与工具栏之外的第三条固定头。

**工作区框架**（任务、自动化详情）：标题栏左侧为返回图标按钮 + 面包屑（`任务 / 标题`，13px，标题 600）+ 状态胶囊，右侧为次要操作、更多菜单与详情开关；下方 44px 页签栏（`协作 / 文件 / 控制台`，tab 28px 填充选中，带计数）；再下为 `内容 | 属性栏 320`。

## 4. 组件

### 4.1 按钮

| 变体 | 外观 | 用途 |
| --- | --- | --- |
| 主 `primary` | `--accent` 实底、白字、无阴影；悬停 `--accent-hover`，按下 `--accent-active` | 每区域一个「下一步」 |
| 次 `secondary`（默认） | `--bg-raised` 底、1px `--border`、`--shadow-xs`；悬停 `--bg-hover` + `--border-strong` | 保存草稿、取消、查看详情 |
| 幽灵 `ghost` | 透明无边框、secondary 字；悬停 `--bg-hover` + 正文色；选中 `--bg-active` | 工具栏、行内、图标按钮 |
| 危险 `danger` | 次按钮外观 + 失败色文字；悬停失败浅底与边 | 删除入口 |
| 危险实底 | `--st-failed` 实底白字 | 确认弹窗里的删除 |
| 提醒 `attention` | 琥珀浅底、琥珀边与字 | 列表行「去澄清 / 去验收」 |

高度 28（sm 24 / lg 32），水平内边距 12（sm 8 / lg 16），字 13/500（sm 12），图标 16（sm 14），图标按钮为正方形。禁用：透明度 .45、无阴影、无指针事件、不响应快捷键。主按钮内的 kbd 反色。按钮组相邻边重叠 1px。

### 4.2 表单

- 输入 / 选择：28px、6px 圆角、1px `--border`、`--bg-input`、左右 12、13px；占位 tertiary。悬停 `--border-strong`；聚焦 `--accent` 边 + 3px `--accent-soft` 外环；错误 `--st-failed` 边，聚焦外环为失败浅底；禁用 `--bg-subtle` + disabled 字。
- 文本域：最小 76px、内边距 8 12、可纵向拉伸；阅读型文本域 14/22。
- 字段：标签 12/500 secondary，必填星号失败色，「可选」tertiary；提示 12 tertiary；错误 12 失败色并带图标；字段间距 16；双列 16 间距，≤860px 单列。
- 开关：28×16，圆点 12，开为 `--accent`。复选 / 单选：15px，选中为 `--accent`。
- 框内多选（picker）：最小 32px，已选为 24px 标签（`--bg-active`、4px 圆角、12/500，可移除），经理标签为 `--accent-soft` + `--accent-border`。
- 搜索框：左侧 16px 图标（内边距 30），可选右侧 kbd 提示（内边距 40）。
- 原生 `select` 一律套共享样式（自绘箭头），不得出现系统默认外观。

### 4.3 分段、页签与视图标签

**所有选中态都是填充底色**（`--bg-active` + 正文色），未选中只有 secondary 文字，悬停 `--bg-hover`；禁止只用下划线或彩色文字表示选中。

- 分段 seg：24px、12/500、项间距 2；图标分段为 24×24。
- 页签 tab（任务工作区）：28px、13/500，计数 11 tertiary。
- 视图标签 vtab（工具栏）：28px、13/500，计数 12 tertiary，待处理计数为琥珀 600。

### 4.4 标签、状态与徽章

- 标签 tag：20px、4px 圆角、11/500、中性浅底 secondary；变体 outline / accent / violet / mono。
- 状态：图标 14px + 12/500 文字（`.status`）；胶囊 22px 全圆角 = 浅底 + 同色字 + 内描边；纯文字版用状态色。状态永远带文字或图标，不只靠颜色。
- 圆点 7px；执行中脉冲环。计数徽章 18px 全圆角 11/600；待处理为琥珀浅底描边。

### 4.5 头像

大圆角方形，圆角 = 边长 × 0.3，身份色实底 + 白字（字号 = 边长 × 0.42，600）。尺寸：16 / 20（列表堆叠，-5px 重叠，2px 底色描边）/ 24（成员行）/ 28（协作消息）/ 36（目录卡片、会话列表）/ 40（详情头）。停用头像灰化（grayscale .85、透明度 .55）。执行中绿点 10px 贴右下角、2px 底色描边、2s 扩散环；经理星标 12px 贴右上角。不得出现圆形头像；成员（数字员工、人类、团队）头像只显示一个字符，扩展（插件 / MCP）头像可用两个字母缩写；群组用双头像叠放。

### 4.6 卡片与目录卡片

- 卡片：`--bg-raised`、1px `--border`、8px 圆角、**无阴影**；可点击卡片悬停边框变 `--border-strong` 并出现 `--shadow-xs`，内容不位移。
- 目录卡片 entity-card（数字员工、插件、MCP 共用，实测 171px 高）：内边距 16、段间距 12；头部 40px = 36px 头像 + 名称（13/600，可跟版本/经理标签）+ 次行（12 tertiary：角色或来源）+ 右侧状态；描述固定两行 40px（13/20 secondary，超出省略）；页脚 33px = 1px `--border-subtle` 顶线 + 8px + 元信息（12 tertiary，14px 图标）与**常驻**操作（ghost sm「对话 / 更新 / 启用」+ 更多菜单）。描述空白或超长都不能改变页脚位置；悬停不覆盖内容；停用卡片头部与描述透明度 .62。
- 网格：`repeat(auto-fill, minmax(min(300px,100%),1fr))`，间距 12。工作流卡片最小 360px，含 `--bg-subtle` 预览区。

## 9. 「无坏界面」验收清单

每一页都要在 **浅色 / 深色 × 1440 / 1180 / 1000 / 860 / 760** 下逐项通过；有任何一项不通过即视为未完成，不能以「截图相近」或「测试通过」代替。

2. **无溢出**：页面无横向滚动；文字不被裁切、不压线、不与相邻元素重叠；长中英文名称单行省略并有 title；按钮文字不换行。
