命令行 CLI

在终端中使用 baton 配置员工、团队、工作流、插件与 MCP，创建和查询任务。

baton已安装
~/.local/bin/baton · v0.1.9
快速开始
baton help
baton schema agents
baton tasks list --json

CLI 复用客户端登录授权，相当于本机管理员权限，只交给可信的 AI。配置保存不等于任务执行，也不能代替你确认交付。

安装说明

仅 Mac 安装包支持，适用于默认配置目录的 zsh / bash；确认窗口会列出将写入的文件。不使用 sudo，不覆盖同名命令。安装后请新开终端；移动客户端后需重新安装。

排查「找不到 CLI」
在日志中搜索 provider.launch_diagnostic，其中包含实际 PATH、目录检查与逐项建议；原始错误在同次调用的 provider.spawn_error 中。分享日志前请检查敏感内容。
保留策略

JSONL 格式，每个进程独立文件，10 MiB 分卷；旧文件按 256 MiB 总量、30 天期限清理，当前分卷保留。
