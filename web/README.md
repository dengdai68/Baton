## 连接视图

设置、插件/MCP市场和手册先读取 `/api/bootstrap?view=connection`，只取得工作目录定位和 businessReady；业务页面继续读取 shell 与分页目录。连接视图不含 installationId 时不得清空本地外观偏好；业务未就绪前导航轮询仅查询连接状态，不以通知查询提前打开数据库。后台自动化与投递恢复仍由服务启动，不依赖页面。

任务草稿的标题与“编辑”操作打开现有任务表单，完整回填目标、验收标准、成员/经理与工作流；保存修改 PUT 原任务，不另建任务。保存并开始先保存再启动，启动失败明确保留修改；保存失败保留输入。已启动任务无编辑入口，服务端仍最终校验；已失效成员显示不可用并要求重选，不静默丢弃；缺失模板显示原选择并要求明确替换。

插件安装沿用同一表单：无清单 Skill 来源由服务端自动包装，卡片/详情显示 Skill 名称与描述。更新、绑定和删除完全复用插件操作；不新增单独 Skill 页面或选择参数。

`toast.mjs` 统一页面反馈，通过手动 Popover 顶层覆盖原生 dialog/媒体/候选蒙层，后来打开浮层也保持通知可见；无焦点抢占、无点击拦截，复用现有语义色和减少动画规则。系统消息由宿主依据已提交业务元数据显示，renderer 不拥有通知发送桥。详见 docs/06、18 与 test-desktop-notifications。

任务中心对齐设计稿（现为石墨：34px 浅底吸顶分组头、单行 38px 任务行）：填充式状态 chips、180ms 即时名称搜索和浮层状态/工作流筛选；连续行按待我处理、进行中、已暂停、草稿、已完成分组，保留下一步、成员头像和更多菜单。组合状态读取现有 HTTP 分页后在客户端筛选与分页，计数对应当前名称/高级筛选范围；归档表格、看板及删除确认不变，无 HTTP/Store/CLI 协议变化。

任务详情在成员前展示可折叠的「协作焦点」，仅依据冻结工作流、交付 Trace 与经理焦点呈现记录事实；任务详情宽屏为320px侧栏，1180px以下改右侧浮层并支持Escape/外部关闭；目录详情抽屉保持独立滚动与固定操作。无 App/CLI/HTTP/Store 契约变化。

控制台增量阅读：`console-stream.mjs` 共用于任务与沟通。接收新记录与阅读位置分离，上滚不再丢弃 SSE 或停掉私聊轮询；底部跟随跨异步正文/布局增长持续有效，回看按可见行锚点保留位置。断线/突发经既有 before 分页补齐最多200条实时窗口，任务可见控制台每5秒补查、沟通每2秒轮询；关闭或隐藏时不补查。最新按钮显式恢复跟随，加载更早记录水平居中。HTTP/Store/CLI协议不变。

显式分页回看的窗口与最新尾部分别保留最多200条；此时新记录进入独立尾部缓存，不会把历史阅读窗口替换为最新页。点击「最新」或滚到历史窗口末尾恢复实时跟随。

## 界面多语言

所有界面文字经 `client/i18n.mjs` 的 `$t("源文本")` 输出，静态壳（index/login/setup）由 `localizeStatic` 翻译；`login.js`、`setup.js` 改为 ES module，登录前即可加载 `/client/i18n.mjs`；当前语言与目录由 preload 的 `batonDesktop.locale` 在页面脚本运行前同步提供。服务端返回的错误、暂停/失败原因、自动化记录原因、更新状态与 Runtime 审计文本在展示点经 `$tm` 翻译；默认工作流名称/步骤与操作者“你”等平台写入记录的文字经 `workflowDisplay` / `partyName` 翻译，成员名称与自定义工作流保持原文。日期与时间按 `intlLocale()` 格式化，zh-CN 保持原格式。设置 → 常规 → 语言提供“跟随系统 / 简体中文 / 繁體中文 / English”，经宿主保存后整页重新加载。清除数据确认词按当前语言输入，提交给服务端的仍是固定源确认词；暂停/终止原因以源文字提交。布局需容纳更长的英文文本，不依赖文字宽度。
